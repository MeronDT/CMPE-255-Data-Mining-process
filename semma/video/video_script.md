# Video walkthrough script — SEMMA: NBA expected FG% (≈ 11 min)

**Setup before recording:** the notebook open in Colab after *Run all* (outputs visible), the GitHub repo in a second tab, the deployed app in a third. Screen-record at 1080p; zoom the browser to ~125 %.

| Time | On screen | What to say (talking points, not a script to read word for word) |
|---|---|---|
| 0:00–0:45 | Title cell | Who you are; the question: *how likely is any NBA shot to go in, given where and how it's taken?* Why it matters: it separates shot **selection** from shot **making**. |
| 0:45–1:30 | SEMMA table in the title cell | SEMMA = Sample, Explore, Modify, Model, Assess, from SAS. Unlike CRISP-DM it starts from the data, not the business, so the project context is one short cell. Each step maps to an Enterprise Miner node. |
| 1:30–3:00 | **Sample**: population table, representativeness table, learning curve, partition | 1.03 M shots across five seasons. The sample is tested against the **unsampled** shots on variables it wasn't stratified on, because matching on the strata proves nothing. The learning curve to 480k shows diminishing returns. Partition 60/20/20 **by game**; 2024-25 held out. |
| 3:00–4:45 | **Explore**: FG% by distance, shot charts, anomalies, variable worth, clusters, corner table | The rim cliff (76 % at 0 ft, 41 % at 5 ft) and the flat mid-range. Corner threes: only +1.8 points at the *same* 24 ft. Heaves: 8 % with ≤ 3 s left from 30+ ft. Leakage catch: `EVENT_TYPE` *is* the target. Player names looked informative until the bias correction (0.022 → 0.008). |
| 4:45–6:00 | **Modify**: drop log, score-code cell, probes, correlation matrix | Every dropped column has a reason. Shot families keep rare labels meaningful (a rare dunk is still a dunk). `shot_features.py` is reused by the app, the Python equivalent of Enterprise Miner score code. The probes show missing values and unseen labels are handled. |
| 6:00–7:45 | **Model**: tuning tables, comparison + bootstrap, ablations | Every family tuned on validation. Why log loss (we need probabilities). Boosting ties the ensemble, so keep the simpler model. Three baselines; the honest gain over zone × shot family is 0.0116. **Ablation:** without the scorer's shot-type label the model is worse than that baseline, so most of the edge depends on the label. |
| 7:45–9:45 | **Assess**: final table, decile + segment calibration, leaderboard, persistence | Train ≈ validation ≈ test → no over-fit. 2024-25: predicted 46.5 % vs actual 46.7 %, deciles within 1.5 points, layups slightly under-predicted. Leaderboard with intervals: Jokić +327 points (+8.5 to +13.6 pts of FG%); only 62 of 181 players clearly differ from average. Persistence r = 0.70, but raw FG% persists more (0.86), so call it a persistent residual. Tell the name-matching bug story (Jokic vs Jokić). |
| 9:45–10:30 | The deployed app | Drag a shot to the left corner, then to the rim; show expected points. Ask for a dunk from 25 ft to show the "unusual shot" warning. Leaderboard tab with intervals. |
| 10:30–11:15 | GitHub repo + critiques folder | Where everything lives; the three critique rounds and what each one changed; limitations (no defender data, post-hoc shot labels); thanks. |
